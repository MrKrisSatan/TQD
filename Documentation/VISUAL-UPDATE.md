# Visual refresh — 0.5.0

The supplied SOVL screenshots are visual references only. No images, branding, interface code or models were extracted from SOVL. The Quiet Dread retains its own science fantasy identity.

Implemented:
- Atmospheric title screen with open serif navigation, teal interaction colours and brass accents.
- Single Player dialog with separate illustrated Trail and Conquest cards.
- Commander selection: faction list, large representative faction painting, real commander selection, difficulty and starting-army customization.
- Seventeen individually generated faction paintings. These are representative faction artwork shared by commanders, not unique canonical depictions of each general.
- Two original painted cartographic backgrounds with real encounter/region connections drawn by Unity.
- Trail node symbols, visited/available states, route lines and legend.
- Conquest ownership colours, region tiers, expedition counts, adjacency lines and settlement order bar.
- Recruitment cards and army-builder thumbnails rendered from the actual native unit models.
- Framed controls, textured ground, improved infantry silhouettes and surrounding battlefield terrain.
- Functional fullscreen, audio level, label visibility and shadow settings. Volume/labels/shadows are persisted locally.
- Modal input isolation, resolution-independent 1600×900 layout and existing 1280×800 raycast checks.

Gameplay rules, existing save version and faction/roster data remain unchanged. The painted maps are background art; overlaid nodes and links define playable geography. Production-quality sculpted 3D units, unique paintings for every named general, animated character portraits, music and voice acting remain outside this visual update.

Validation evidence lives in TEST-RESULTS.txt, BUILD-RESULT.txt and ../QA/runtime-smoke.txt. QA screenshots cover menu, mode dialog, settings, commander selection, army builder, recruitment, campaigns, battlefield, results, titan gallery, faction-art gallery and resized rendering.
